# ea-site

Single-page static landing site for Cameron Reece Allcock's MetaTrader 5 Expert Advisors (v1).

- `index.html` + `assets/styles.css`: no frameworks, no CDNs, system fonts, a few lines of inline JS for the form note.
- `assets/img/`: EA logos and on-chart controls screenshots (no backtest or results images).
- `preview/`: desktop (1440 px) and mobile (390 px) full-page screenshots.

Open `index.html` in a browser to view it. Nothing is deployed.
